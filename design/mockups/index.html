Onyx Sheiko: three design directions

Clickable mockups for issue #6. All three use the same made-up data, so they compare fairly. Try ⌘K (or Ctrl+K), the ◐ theme toggle, opening notes and wikilinks, and moving a task forward a stage.

A

Workspace

Three panes: note tree, editor, a details panel with backlinks and related tasks. Dense and keyboard-first.
B

Board-first

Tasks as a board by stage, with a list toggle and project filter. Notes and task details open in a slide-over.
C

Dashboard + focus

A calm home screen: due today, waiting for sign-off, recent notes. Anything opens full-width with no distractions.

Mockups only. They load Tailwind's in-browser build from a CDN, pinned to 4.3.3 with an integrity hash; the real app will ship a built CSS file under a strict Content Security Policy. Nothing is saved: changes reset on reload.
