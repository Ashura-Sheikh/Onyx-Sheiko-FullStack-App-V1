# Dev vault

An **entirely made-up** vault for developing and testing Onyx Sheiko. Every name, project, date and sentence here is invented.

Every file starts with `synthetic: true` in its frontmatter, and a test fails if one doesn't, or if any file contains an absolute path, an email address or a URL outside `example.com`.

- Notes: `Projects/`, `Meetings/`, `Reference/`, `Journal/`
- Tasks: `Tasks/`, in TaskNotes-style frontmatter with a `## Status History` section
